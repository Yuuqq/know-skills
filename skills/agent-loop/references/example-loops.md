# Example Loop Fragments

Use these only to calibrate shape. Do not copy them wholesale.

## Platform Text Analysis

- Research question / goal: Explain how climate-risk responsibility is framed by
  verified organizations on a platform during a policy window.
- Unit of analysis: One organization-authored post.
- Intended claim: A bounded descriptive claim about framing prevalence and
  variation, not causal effect.
- Corpus boundary: Verified organization accounts, defined policy dates, query
  log retained, deleted/private content excluded.
- Progress invariant: Fewer unresolved construct-validity threats across frame
  labels and fewer unaudited LLM annotations.
- Evidence chain: raw post id -> cleaned text -> frame label -> audit sample ->
  prevalence table -> limitations paragraph.
- Truth source: raw post text and human-audited labels; LLM frame labels are
  measurement artifacts until audited.
- Research trace: query changes, exclusions, prompt versions, audit disputes,
  and failed frame definitions are logged.
- Decision record: final frame codebook records rejected frame definitions and
  validity risks.
- Paper mapping: method corpus table, result frame table, appendix codebook,
  limitations platform coverage.

## Network Analysis

- Research question / goal: Identify brokerage patterns among organizations in a
  public collaboration network.
- Unit of analysis: Organization node and time-bounded collaboration edge.
- Intended claim: Structural brokerage patterns, not hidden influence or intent.
- Corpus boundary: Public partnership records in a defined domain and period.
- Progress invariant: Fewer unresolved edge-definition and boundary-sensitivity
  risks.
- Evidence chain: source record -> node normalization -> edge construction log
  -> network diagnostics -> robustness to alternative edge rules -> result.
- Truth source: public partnership record and normalized organization identity;
  centrality and community measures are derived artifacts.
- Research trace: node merges, edge-rule changes, missing records, and abandoned
  boundary definitions are logged.
- Decision record: selected edge definition records rejected alternatives,
  scope risk, and robustness checks.
- Paper mapping: method node/edge definitions, result centrality/community
  table, robustness appendix, limitations missing partnerships.
